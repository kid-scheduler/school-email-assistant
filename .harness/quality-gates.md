# Harness Quality Gates

Quality gates will evolve as the project gains code.

## Current Documentation Phase

Before considering documentation work complete:

- Markdown is formatted.
- Public docs contain no private local paths, credentials, raw school emails, or private project references.
- Open questions are updated when new uncertainty is discovered.
- Related outline/blog/harness docs are updated when project direction changes.

## Future Implementation Phase

Expected checks once code exists:

- Format
- Lint
- Typecheck
- Unit tests
- Fixture replay
- UI mock contract checks
- Accessibility checks for user-facing flows

Exact commands should be added here once the implementation tooling is selected.
